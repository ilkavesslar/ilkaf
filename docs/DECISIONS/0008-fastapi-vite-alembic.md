# ADR 0008: FastAPI, SQLAlchemy 2, Alembic, Vite for the foundation

- **Status:** Accepted (Sprint 0)
- **Date:** 2026-08-20

## Context

P1/P2/P10 were provisional. Sprint 0 needs a runnable API, UI shell, and migrations.

## Decision

- Backend: Python 3.11+, **FastAPI**, **SQLAlchemy 2** (async).
- Migrations: **Alembic**.
- Frontend: **React + TypeScript + Vite**.
- Auth **protocol** is OIDC (see ADR 0010). Sprint 0 shipped role names and tables only.

## Consequences

Replacing FastAPI later needs a new ADR. OpenAPI is generated by FastAPI (A4).
