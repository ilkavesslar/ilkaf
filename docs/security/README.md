# Security & Compliance Architecture

This directory outlines the security controls, threat vectors, identity management, and compliance governance.

## Key Focus Areas
- **Threat Modeling (STRIDE)**: Analysis of video tampering, unauthorized stream interception, spoofed alerts.
- **RBAC Matrix**: Permissions for Plant Operators, Safety Officers, System Administrators, and Auditors.
- **Data Protection & PII**: Frame redaction/blurring policies for worker privacy compliance.
