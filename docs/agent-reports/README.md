# Agent reports

Non-trivial handoffs only (not typo fixes). Suggested names:

| File | Author |
| :--- | :--- |
| `architecture-review.md` | Architect |
| `implementation-report.md` | Builder |
| `qa-report.md` | QA/Security |
| `ai-cv-review.md` | AI/CV |
| `multi-agent-dry-run.md` | Combined dry-run |

Template:

- Objective  
- Files inspected  
- Files changed  
- Decisions  
- Tests  
- Unresolved issues  
- Risks  
- Recommended next action
